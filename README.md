# marknotes-api

Server to manage markdown based notes.

```bash
{
    "/check-grammar": "checks grammar of markdown notes",
    "/list-notes": "list saved markdown notes",
    "/parse-html": "parse markdown note into html",
    "/save-notes": "save markdown notes"
}
```

Inspired from [roadmap.sh/projects/markdown-note-taking-app](https://roadmap.sh/projects/markdown-note-taking-app)
